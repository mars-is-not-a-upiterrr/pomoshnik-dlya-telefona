ПОМOЩНИК ДЛЯ ТЕЛЕФОНА — СТАРТОВЫЙ ПРОЕКТ

ВАЖНО
Это стартовая сборка проекта, восстановленная по описанию предыдущей версии.
Она сохраняет общую идею (6 плиток, крупные кнопки, пошаговые инструкции), но
не является точной копией прежнего ZIP: исходные CSS/JS файлы старой версии
в этой сессии недоступны. Сначала проверьте эту сборку, прежде чем публиковать.

СТРУКТУРА
index.html              приложение для бабушки
admin.html              редактор инструкций для тебя
styles.css              общий дизайн
app.js                  логика приложения
admin.js                логика редактора
data/instructions.json  инструкции и шаги
sw.js                   офлайн-кэш
manifest.webmanifest    установка PWA
icons/icon.svg          иконка
worker/worker.js        защищённый издатель в GitHub
worker/wrangler.toml    настройки Cloudflare Worker

ПУБЛИКАЦИЯ ПРИЛОЖЕНИЯ
1. Создайте новый GitHub repository.
2. Загрузите содержимое этой папки в корень репозитория (не саму папку-обёртку).
3. В Settings -> Pages выберите Deploy from a branch, ветка main, папка /(root).
4. Сохраните адрес GitHub Pages. Обычно он выглядит как
   https://ВАШЕ_ИМЯ.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/

НАСТРОЙКА РЕДАКТОРА
Редактор admin.html пока умеет загружать JSON и редактировать инструкции
в текущем окне. Для публикации необходим Cloudflare Worker.
Потребуются:
- Cloudflare аккаунт
- GitHub Personal Access Token с доступом Contents: Read and write только
  к этому репозиторию
- секреты Worker: ADMIN_PASSWORD и GITHUB_TOKEN
- переменные GITHUB_OWNER, GITHUB_REPO, GITHUB_BRANCH, ALLOWED_ORIGIN

Worker сейчас публикует data/instructions.json. Для публикации файлов изображений
в GitHub потребуется следующий этап разработки: в этой стартовой версии
загруженные в редактор изображения сохраняются в данных как Data URL. Это
подходит только для небольших тестов и не рекомендуется для постоянного
использования. Перед реальной эксплуатацией добавим отдельную загрузку файлов
изображений в папку images/ и ссылки на них в JSON.

НЕ ПУБЛИКУЙТЕ GITHUB TOKEN В РЕПОЗИТОРИИ И НЕ ВСТАВЛЯЙТЕ ЕГО В HTML/JS.
Не используйте эту стартовую сборку как готовую защищённую production-систему,
пока не завершена настройка и проверка Worker.
